# 버튼 호버와 포트 클릭 영역 통일

## 영향 도메인과 수용 기준

메뉴바 UI가 대상이며 `docs/spec.md` S27과 `docs/domain-contract.md`를 따릅니다. 원본 처리·SSH 설정·사용자 클립보드는 변경하지 않습니다. 팝업과 목록 높이, 빠른 등록 입력·IME를 유지하고 추가 폴링을 만들지 않습니다.

## Step 1

- 목표: 활성 버튼의 호버 강조·손 모양 커서와 일관된 서버 열기 영역을 제공합니다.
- 변경 파일: `macos/Models.swift`, `macos/Dashboard.swift`, `macos/Verification.swift`, 명세·사용법·검증 기록.
- [x] 포트 왼쪽 320 point를 단일 버튼으로 구성하고 오른쪽 24 point 상세 버튼을 분리합니다.
- [x] 표시용 자식 뷰는 클릭을 가로채지 않습니다.
- [x] 연결 가능일 때만 열기를 활성화하고 OFF·대기·충돌에는 이유를 표시합니다. 상세는 사용할 수 있습니다.
- [x] 이벤트 기반 호버 강조·커서와 비활성 동작 차단을 구현합니다.
- [x] native hitTest·호버 픽셀·콜백·기존 입력 회귀 및 light/dark 렌더를 확인합니다.
- [x] 두 병렬 리뷰 후 문서·로컬 커밋·기존 전체 사용자 설치본 갱신을 완료합니다.

## 실행 규칙

명세 → 실패 테스트 → 구현 → 검증 → 스펙/코드 병렬 리뷰 → 수정·재검증 → 문서 동기화 → 로컬 커밋 순서입니다. 기존 설치 요청에 따라 `/Applications/Worklink.app`을 갱신합니다. GitHub 작업과 제품 앱 자동 재시작은 하지 않습니다. CUA 접근 거부를 다른 UI 자동화 수단으로 우회하지 않습니다. native 테스트의 합성 이벤트·렌더 검증과 실제 제품 마우스 검증을 구분합니다.
