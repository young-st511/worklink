# 도메인 불변 규칙

- 원본 이미지 byte·형식 유지. 압축·리사이즈·재인코딩 없음.
- 캡처당 ID 1개, retry에도 동일 원격 파일. 원격 ACK 후에만 로컬 임시 파일 삭제.
- 클립보드는 원래 changeCount와 업무 generation이 일치할 때만 원격 경로로 변경.
- 전체 리스너 탐색 없음. 등록한 loopback endpoint만 관리. 기존 프로세스/SSH master는 종료하지 않음.
- OFF에서는 감지·통신·재연결을 정지. 로그인 후 OFF. 우클릭 1회 토글, dimmed/모양과 상태 텍스트.
- 정리는 전용 inbox의 관리 기록·파일명·생성 시각이 일치한 24시간 지난 완료 파일만 삭제. pin 제외.
- 실제 계정·호스트·개인 이미지·인증정보를 커밋하지 않음. 로컬 Git만 사용.
- 검증: Go race/test/vet, 별도 inbox 원본 해시/만료 경계, 네이티브 UI 렌더 확인, 실제 SSH 테스트 여부와 측정 한계 기록.
