# Worklink

집의 Mac과 사무실의 Mac 사이에서 개발 서버 연결과 스크린샷 전달을 묶는 작은 업무 도구입니다.

Tailscale + SSH + Zellij + 터미널 코딩 에이전트를 사용하는 환경을 대상으로 합니다. 업무 모드를 켜두면 이미지 전달과 등록된 포트 연결을 관리하고, 업무를 마치면 감지와 연결을 멈추는 macOS 메뉴바 앱을 구상하고 있습니다.

**현재 상태: 타당성 검토와 로컬 측정 실험. 실제 동기화 앱은 아직 구현하지 않았습니다.**

## 검토 결론

구현 가능성이 높습니다. 비용을 좌우하는 것은 언어보다 **확인 주기, 프로세스 생성 횟수, 이미지 변환, 재연결 방식**입니다.

- 로컬은 네이티브 메뉴바 앱, 통신·전송 코어는 Go를 우선 검토합니다.
- 기존 Tailscale과 시스템 OpenSSH를 재사용하고, Worklink 전용 SSH 연결 하나에서 제어·전송·포트 전달을 처리합니다.
- 클립보드 변경 번호를 1초 간격으로 확인하고, 바뀐 경우에만 이미지 처리 단계로 넘어갑니다.
- 개발 서버를 실행할 때 포트를 등록하거나 자주 쓰는 포트를 지정합니다. 임의 프로세스의 포트 자동 발견은 별도 선택 기능으로 검증합니다.
- 이미지 도착 후 에이전트에 전달할 원격 경로를 제공합니다. 터미널 입력을 자동으로 보내지는 않습니다.

전체 앱의 저전력 동작은 아직 검증하지 않았습니다. [타당성 검토](docs/feasibility.md), [동작 설계](docs/design.md), [개발 순서](docs/roadmap.md)에 판단과 남은 실험을 기록했습니다.

## 비용 측정 실험

macOS와 Xcode Command Line Tools가 필요합니다. 외부 패키지는 없습니다.

```sh
make probe
.build/clipboard-cost timer-only 30 1
.build/clipboard-cost clipboard 30 1
```

실험은 지정한 시간 후 종료합니다. 클립보드 변경 번호만 읽으며 이미지·텍스트 내용을 읽거나 덮어쓰지 않습니다. SSH 연결, 네트워크 전송, 상주 서비스 설치도 수행하지 않습니다.

Python 3가 있다면 `python3 experiments/listener-cost.py`로 현재 사용자 소유 TCP 리스너 검색 비용을 30초 동안 측정할 수 있습니다. 소켓·프로세스 목록은 저장하지 않습니다.

JSON 출력의 CPU 비율은 한 코어를 100%로 보는 **실험 프로세스만의 실행 중 평균**입니다. 메모리는 초기화를 포함한 최대 RSS입니다. 타이머 콜백 수는 시스템의 실제 wakeup 수가 아닙니다. 측정 방법과 한계는 [실험 기록](docs/measurements.md)을 확인해 주세요.
